# 藻类细胞分裂谱系复原

从连续荧光帧的候选细胞斑点中，**联合选择**斑点与帧间连接，恢复一株藻细胞的
分裂谱系。计算全部在浏览器内完成，不上传任何数据。

## 生物学 / 组合模型

- 录入 **4 至 7 个**按时刻排列的帧，每帧 **2 至 8 个**唯一斑点
  （整数坐标 x/y、整数亮度）。
- 连接只允许：
  - **相邻帧**（`gap=1`）：位移 ≤ 相邻帧最大位移；
  - **跨恰好一帧漏检**（`gap=2`）：中间帧无该细胞斑点，两端直线位移
    ≤ 2 × 最大位移，受「允许漏检帧数」总额度约束。
- 一个细胞每步要么**保持为一个后代**，要么**分裂为恰两个后代**，不允许消亡。
- 每个非起始斑点**恰有一个祖先**；同一斑点不得被两支同时采用。
- 所有存活支必须从**起始斑点**出发到达末帧，末帧存活细胞数恰为设定值。
- **分裂不应期（可选，门槛 2–4 个帧间）**：启用后起始细胞的**首次分裂不受限**，
  此后每个分裂女儿从 0 累计「分裂年龄」——普通（相邻帧）连接增加 **1** 个帧间，
  跨一帧漏检连接按真实跨度增加 **2** 个帧间，年龄达到门槛后才允许再次分裂。
  求解器在联合选择斑点与连接时即为每条存活支携带分裂年龄（不是先按原规则
  求出谱系再删除过早分裂）；未启用时输入、结论与证据与旧版完全一致。
- 裁决顺序（依次比较）：
  1. 采用斑点**总亮度最高**；
  2. **漏检段数最少**；
  3. **输入顺序稳定裁决**：逐帧比较采用斑点的输入序号，再比较母本编号。

因此不会逐帧贪心挑选最亮斑点而把杂质或不同个体串成同一支。

当终帧目标数与祖先/位移/漏检约束无法同时满足时，编辑草稿保留，页面指出
**最早断开的帧间**（如「第 1 帧 → 第 2 帧」）。若所有候选都要求某条支在不应期
内过早再次分裂，还会指出**最早被不应期阻断的帧间、母细胞及其尚缺的等待帧间数**。
任一帧或限制（含不应期开关与门槛）被修改后，旧谱系立即作废并提示重新复原
（草稿保留在编辑区与浏览器 localStorage）。

## 本地运行（无需 Docker）

需要 Node.js ≥ 20（零第三方依赖）：

```bash
npm start                 # 默认 http://localhost:8080
WEB_PORT=9000 npm start   # 自定义端口
```

## Docker 运行

```bash
docker compose up web --build        # 浏览器打开 http://localhost:8080
WEB_PORT=9000 docker compose up web  # 用 .env 或环境变量自定义端口
```

网页端口完全由 `WEB_PORT` 控制（`.env` 可参考 `.env.example`）。

## verify 一次性校验服务

健康检查通过后，`verify` 服务自行执行**单元测试 → 构建 → 含分裂、漏检与分裂
不应期的谱系烟测**，并以容器退出码报告结果：

```bash
docker compose up --build \
  --abort-on-container-exit --exit-code-from verify
echo $?    # 0 表示全部通过
```

三项也可不依赖 Docker 直接运行：

```bash
npm test     # node:test 单元测试（含 ~3000 组随机输入与独立暴力枚举对拍，覆盖不应期）
npm run build  # 语法检查 + 静态资源完整性 + 构建清单
npm run smoke  # 健康检查 / 静态资源 / 分裂+漏检谱系 / 连续分裂阻断 / 跨漏检计龄
```

## 求解方法

带备忘的深度优先联合枚举：状态为「某帧边界上的存活斑点集合 + 正在漏检中的
母本集合 + 剩余漏检配额 + 每条存活支的分裂年龄向量」，逐帧联合决定每支的
保持/分裂/漏检（启用不应期时分裂候选还要求母支年龄达门槛），并在同一转移内
保证斑点不被两支共用；同一状态的最优后缀只求解一次。未启用不应期时各支年龄
统一，状态与旧版完全合并，无额外开销。配合末帧目标数的增长上界剪枝，
在 4–7 帧、每帧 ≤8 斑点的规模下即时返回。不可行时通过前向可达性（携带年龄）
与后缀可行性，定位最早没有任何可行谱系穿过的帧间；若放宽年龄约束后即出现可行
后缀，则把该帧间归因为分裂不应期阻断，并给出被迫过早分裂的母本与其尚缺的
等待帧间数。
